# Ctrl2Enter — 双击触发键发送 Enter（AutoHotkey v2）

把任意「触发键」变成 Enter：在设定间隔内**双击**它即发送 Enter；**单独按 / 长按**保持原始按键功能不变。
默认触发键为 `Ctrl`，双击 Ctrl 即回车。

- **作者**：SantaChains
- **版本**：v0.0.1
- **仓库**：[SantaChains/keyshadow](https://github.com/SantaChains/keyshadow)

---

## 一、功能特性

- **双击即回车**：在「连按窗口」内第二次按下触发键，补发 `Enter`。
- **原键位零影响**：采用 `~` 透传，原生按键始终放行。单击、长按（如 `Ctrl+C` / `Ctrl+V` 这类组合）完全不受影响。
- **可调间隔**：连按窗口 50–1000 ms 可调，默认 300 ms（兼顾灵敏度与误触）。
- **托盘控制**：打开设置 / 映射开关 / 开机自启 / 退出；**默认隐藏系统托盘**。
- **设置热键**：默认 `Ctrl+Alt+S` 随时打开设置（即使托盘隐藏也可使用）。
- **配置持久化**：设置存于 `%APPDATA%\Ctrl2Enter\config.json`，自研 JSON 读写，无外部库。

## 二、系统要求

- Windows 7+（推荐 Windows 10/11）
- [AutoHotkey v2.0+](https://www.autohotkey.com/)（**必须是 v2**；编译后的 exe 无需安装）

## 三、快速开始

**方式 A — 直接运行脚本**

```
Ctrl2Enter.ahk
```

**方式 B — 编译为独立 exe**

```
build.cmd
```

生成 `Ctrl2Enter.exe`，无需安装 AutoHotkey 即可运行。

首次运行会自动打开设置窗口（因默认隐藏托盘，借此告知用法）。

---

## 四、使用说明

1. 程序启动后常驻后台；双击 `Ctrl`（默认）即发送 Enter。
2. 单击 `Ctrl`、或长按 `Ctrl`（含 `Ctrl+其他键` 组合）均按原本功能工作。
3. 打开设置：
   - 托盘菜单「打开设置…」（若已在设置中勾选「显示系统托盘图标」）；
   - 或随时按 `Ctrl+Alt+S`。
4. 在设置中可修改：触发键（点击按钮后按一下目标键）、连按窗口、功能开关、开机自启、是否显示托盘、打开设置热键。
5. 修改后点击「应用并保存」生效。

**暂停 / 恢复**：托盘菜单「映射已启用」可快速开关（双击 Ctrl 不再发送 Enter）。

## 五、关于「双击间隔」

连按窗口决定两次按下的最大间隔。经验参考：

| 取值 | 效果 |
| --- | --- |
| 偏小（如 150–250 ms） | 响应快，但连续两次独立操作易被误判为双击 |
| 默认 300 ms | 接近 Android 双击超时，手感平衡 |
| 偏大（如 500–800 ms） | 更不易误触，但需刻意加快连按 |

> 边界说明：本工具对「双击」的判定基于两次触发键按下的时间间隔。若在窗口期内先做了
> `Ctrl+某键` 之类的组合再按第二次 Ctrl，也会被判定为双击并发送 Enter。若你频繁在极短时间内
> 连续使用 `Ctrl` 组合键，可适当调大连按窗口，或改用不常参与组合的键（如 `CapsLock`、`F13`）作为触发键。

## 六、配置说明

配置文件：`%APPDATA%\Ctrl2Enter\config.json`

```json
{
  "trigger": "LCtrl",
  "tapWindowMs": 300,
  "enabled": 1,
  "autostart": 0,
  "trayHidden": 1,
  "settingsHotkey": "^!s"
}
```

- `enabled`：`1` 启用映射，`0` 暂停（布尔在 AHK v2 中以 `1`/`0` 存储）。
- `trayHidden`：`1` 隐藏托盘（默认），`0` 显示。
- 直接编辑后重启程序生效；损坏的文件会被忽略并回退默认值。

## 八、打包（编译为 exe）

根目录 `build.cmd` 一键编译并嵌入 `logo.ico`：

```

```

脚本自动定位 `AutoHotkey\v2\AutoHotkey64.exe` 作为 `/base`，规避 v2 脚本用旧版 Ahk2Exe 编译失败（返回码 52）的问题。
